# Documentation du projet IAD & SmartQueue AI

Bienvenue dans la documentation officielle du projet **IAD & SmartQueue AI**. 
Ce système est une plateforme d'intelligence artificielle combinant la vision par ordinateur (Computer Vision) et l'apprentissage automatique (Machine Learning) pour analyser des flux vidéo en temps réel et optimiser la gestion des files d'attente.
